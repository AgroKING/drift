## ✨ Overview

Every developer has a dirty secret: things they've forgotten about. That PR review they meant to do Monday. That Slack thread they never responded to. That sprint task that's been 'In Progress' for two weeks with zero commits. We call this **Attention Debt**. 

This repository contains the **Frontend Web Dashboard** for Drift. It is a highly optimized, stateless, single-page Flutter Web application that visualizes a developer's attention debt by consuming a unified JSON data contract generated by our Coral-powered Python agent.

## 🚀 Key Features

* **Enterprise Light Theme UI:** A clean, professional, and accessible interface optimized for desktop and presentation displays.
* **The "Attention Debt" Score:** A unified metric (with historical deltas) that quantifies neglected tasks across disparate tools.
* **Interactive Debt Cards:** Beautifully categorized, expandable components for:
  * 🔴 **Review Debt** (Pending GitHub PRs)
  * 🟠 **Reply Debt** (Unread Slack & Notion mentions)
  * 🟡 **Commitment Debt** (Stale Linear tasks with no Git activity)
  * 🔵 **Staleness Debt** (Forgotten personal work)
  * 🟣 **Drift Debt** (Cross-tool contradictions)
* **Action Routing:** Deep-linking directly to specific PRs, Slack threads, and Linear tickets via actionable URL launchers.
* **Live / Mock Data Toggle:** Seamlessly switch between static mock data (for reliable presentations) and live data fetched from the local agent server.
* **Architecture Visualization:** Built-in interactive diagrams explaining the Coral → Agent → UI data flow.

## 🛠️ Tech Stack

## 🔌 The Data Contract

To keep our architecture clean and fast for the hackathon, this frontend is entirely decoupled from the backend orchestration. It relies strictly on a `drift_report.json` schema. 

The UI expects the backend agent to do the heavy lifting (cross-tool SQL JOINs via Coral, API pagination, and scoring) and simply render the output. This allows the UI to be blazingly fast and independently testable.

## ⚙️ Getting Started

To run the Drift dashboard locally on your machine:

### 1. Prerequisites
Ensure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed and configured for web development.

### 2. Installation
Clone the repository and install the required dependencies:
```bash
git clone <repository-url>
cd drift/frontend
flutter pub get
```

### 3. Running the App
Launch the app in your default web browser (Chrome recommended for optimal presentation):
```bash
flutter run -d chrome
```
OR

Launch using run_frontend.sh for a more streamlined experience:
```bash
./run_frontend.sh
```

### 4. Live vs Mock Mode
By default, the UI will load data from assets/mock_drift_report.json. To connect to the live backend:
1. Ensure the Python agent is running and serving drift_report.json on http://localhost:8080.
2. Toggle the "📁 MOCK DATA" switch in the top right of the dashboard to "📡 LIVE MODE".
