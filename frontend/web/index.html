FAQs

Everything you need to know about the Drift ecosystem

❓ What is Coral?

Coral serves as the foundational context management layer, unifying and standardizing raw real-time event updates from disparate developer tools into actionable team metrics.

❓ What is Drift?

Drift is an automation and attention debt visibility engine built on top of Coral. It flags cross-tool contradictions, calculates context blockages, and highlights stuck items across platforms.

❓ What is Attention Debt?

Attention debt accumulates when cross-tool tasks get stranded—such as code reviews left waiting in GitHub or action items discussed in Slack that haven't been tracked in Linear.

❓ How does Drift find tool contradictions?

Drift reads background metadata from your integrated platforms to flag mismatches, like a task marked 'Done' in Linear while its corresponding GitHub PR is still open and unmerged.

❓ Does this require complex local installation?

Not at all. The interface operates completely as a lightweight web app reading structured JSON data contracts generated by a lightweight background agent.

❓ How frequent are the synchronization cycles?

Synchronization runs dynamically via background daemon processes, ensuring your dashboard metrics refresh instantly as work updates across tools.

❓ Which platforms are supported by Coral?

Currently, the platform fully supports deep bidirectional context tracking for GitHub, Linear, Slack, and Notion.

❓ How is the score calculated?

The score aggregates unaddressed cross-tool items weighted by their stagnation delta time, providing a tangible metric where positive numbers indicate an increasing bottleneck.

Core Architecture

Drift unifies context across developer platforms using the **Coral Context Engine**. The background synchronization processes fetch raw event feeds from GitHub, Linear, Slack, and Notion APIs, normalizing them into a shared schema.

CORAL LIFECYCLE

Raw Event Feeds → Normalization → Conflict Resolution → JSON Report → Dashboard Render.

Configuration

Integration credentials and polling settings are stored in the local `.env` configuration file located at the project root directory. 

# Port Configuration
PORT=8080

# GitHub Integration
GITHUB_TOKEN=ghp_yourPersonalAccessTokenHere
GITHUB_OWNER=acme-corp

# Linear Integration

Privacy

Learn how Drift and Coral protect your proprietary codebase and communication metadata.

shield Local-First Security Architecture

Unlike traditional SaaS analytics platforms, **Drift is built on a local-first design pattern**. The Coral sync engine runs completely on your local workstation or private virtual server environment.

  • Zero Cloud Relays: Raw Slack messages, Linear task details, and GitHub code changes never pass through third-party servers.
  • Local Storage Only: The compiled context report `drift_report.json` remains entirely in your local storage directory.
  • No Telemetry: Drift does not track usage patterns, click maps, or dashboard configurations.

API Data Isolation

To interface with developer APIs, Drift uses standard OAuth2 or personal access token integrations. All credentials remain encrypted in your local `.env` configuration file, loaded into temporary environment memory at runtime, and are never serialized or transmitted.
